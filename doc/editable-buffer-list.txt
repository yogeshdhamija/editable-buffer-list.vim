*editable-buffer-list.txt*  The buffer list as an editable buffer

Author: Yogesh Dhamija <yogeshdhamija@outlook.com>

                                                                 *:BufferList*
:BufferList		Show the buffer list in the current window as a plain,
			editable buffer. Edits take effect immediately -- there
			is nothing to save -- and the list updates itself as
			buffers change elsewhere.

The list is |:ls| output, with hints above it: >

  see :h :BufferList | Updates Live!
  <CR> to open | delete line to :bdelete | u to undo
  gs to sort: [name]/used/created
  # = alternate | h = hidden | no a or h = unloaded | + = modified
  ──────────────────────────────────────────────────────────────────────────
    1  h + "init.vim"
    2      "notes.txt"
    3 #h   "plugin.vim"
<
`#` marks the buffer you were on before opening the list. The legend only
explains flags that appear in the list; see |:ls| for all of them. Hints need
Neovim or Vim 9.0.0451+.

==============================================================================
USAGE

<CR>		Open the buffer under the cursor. CTRL-^ then goes back to
		the buffer you were on before the list, so this is also how
		to leave without picking anything.

Deleting lines	Any way of deleting lines -- `dd`, `5dd`, `Vd`, `:g/foo/d` --
		runs |:bdelete| on those buffers. A buffer with unsaved
		changes refuses: its line comes back and the error is shown.

Adding lines	Putting a deleted line back (`p` after `dd`), or typing a
		buffer number on a line of its own, relists that buffer.

                                                   *editable-buffer-list-undo*
u  CTRL-R	Undo or redo your last change to the list; takes a count.
		Deleted buffers come back unloaded, but windows closed by
		|:bdelete| stay closed. History is shared by all lists and
		survives leaving the list. Vim's other undo commands (`U`,
		`g-`, |:undo|, ...) do nothing here.

                                                   *editable-buffer-list-sort*
gs		Cycle the sort order of every list:
		    name	alphabetical, ignoring case (default)
		    used	most recently used first
		    created	newest buffer first

Only the buffer number at the start of a line matters. Mangle the rest and the
line is just redrawn.

==============================================================================
OPTIONS

                                       *g:editable_buffer_list_delete_command*
g:editable_buffer_list_delete_command	(default: "bdelete")
	Command run on each deleted buffer, with the buffer number appended.
	|:bdelete| closes every window showing the buffer; to keep them open,
	use something like vim-bbye's `:Bdelete`: >
		let g:editable_buffer_list_delete_command = 'Bdelete'
<	The command must unlist the buffer, not wipe it, or `u` can't bring
	it back.

                                                *g:editable_buffer_list_hints*
g:editable_buffer_list_hints		(default: 1)
	Set to 0 to hide the hints.

                                                 *g:editable_buffer_list_sort*
g:editable_buffer_list_sort		(default: "name")
	Starting sort order: "name", "used" or "created". `gs` changes it.

==============================================================================
FUNCTIONS

                                        *editableBufferList#PathUnderCursor()*
editableBufferList#PathUnderCursor()
	Full path of the buffer under the cursor, or "" if there is none.
	Handy for a copy-path command that also works in the list: >
		function! CopyPath() abort
		    let @+ = &filetype ==# 'bufferlist'
		        \ ? editableBufferList#PathUnderCursor() : expand('%:p')
		endfunction
		command! CP call CopyPath()
<
